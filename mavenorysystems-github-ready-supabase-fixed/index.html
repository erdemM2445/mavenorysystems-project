FAQ

Clear expectations before purchase.

Is this only for Etsy?

No. The wording is Etsy-friendly, but the logic works for any small handmade shop that can provide product costs, labor time and sales rows.

Does it automatically import CSV files?

The current version includes a CSV paste/staging workflow. It is flexible across marketplace exports, but it is not a fully automatic integration.

How many products can it handle?

The planner version is designed around up to 100 products before custom expansion.

What decisions does it produce?

It turns SKU performance into Keep, Raise Price, Restock, Stop, Test More and Order Now signals.

Is this accounting software?

No. It is an operational planning and decision tool. It does not replace bookkeeping, tax advice or accounting software.

Will there be updates?

The workbook includes a member access and changelog structure for updates, support and a future web app beta path.
